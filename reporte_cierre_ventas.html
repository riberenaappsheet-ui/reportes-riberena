🔧 Guía de integración — cómo generar la URL desde AppSheet

Pega esta URL en el campo de acción de AppSheet (Open a URL).
Los arrays productos / clientes / despachados / noVendidos van como JSON codificado con ENCODEURL().

Parámetros disponibles:
idRuta · fecha · despacho · horaInicio · horaFin · responsable · estatus
totalClientes · totalVenta · totalEfectivo · totalLts · totalProductos
totalTransferencia · totalCredito · totalDeposito · totalEgresos · balanceCierre
productos → JSON: [{"producto":"...","presentacion":"...","precio":0,"canPres":0,"cantidad":0}]
clientes → JSON: [{"cliente":"...","efectivo":0,"transferencia":0,"totalVenta":0}]
Auditoría de inventario:
despachados → JSON: [{"producto":"...","cantidad":0}] — de GCB_DESPACHO_DETALLES
noVendidos → JSON: [{"producto":"...","cantidad":0}] — de GCB_DESPACHO_NO VENDIDO
Los vendidos se calculan automáticamente desde el array productos ya existente.
